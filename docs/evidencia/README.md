# Evidências de campo

Arquivos desta pasta registram somente marcadores estruturais necessários para
reproduzir conclusões de integração. Não entram aqui cookies, tokens, CPF,
senha, unidade consumidora, nome do titular, valores ou query strings.

`equatorial-bridge-2026-08-22.jsonl` é a seleção mínima da trilha privada de 18
passos produzida no Poco pelo APK ROD 1.0.3 (versionCode 35). A trilha completa
foi auditada antes da seleção: zero identificadores conhecidos, zero sequências
de oito ou mais dígitos, zero query strings e zero chaves de segredo.

Conclusão observada: a sessão do portal `go.*` estava válida, mas o host
`goias.*` continuou exigindo seu próprio login. Portanto, a sessão não atravessa
os dois portais e essa ponte não pode ser apresentada como canal de fatura.
